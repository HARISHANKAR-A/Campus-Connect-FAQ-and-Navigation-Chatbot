# Campus Connect : FAQ and Navigation Chatbot 🚀

Campus Connect is a specialized conversational assistant designed to help incoming freshers navigate life at VIT Vellore. The chatbot bridges the information gap by instantly answering frequently asked questions while providing intuitive, location-based navigation support.

## ✨ Key Features
* **Fresher FAQ Resolution:** Instant, automated answers to common queries regarding academics, campus facilities, hostel life, and administrative procedures at VIT Vellore.
* **In-Campus Navigation:** Directs users seamlessly to campus landmarks, academic blocks, and facilities by integrating with Google Maps routing.
* **User-Friendly Interface:** Built for quick accessibility and effortless interaction.
